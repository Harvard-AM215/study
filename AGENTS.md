# AM115/AM215 study folder

This folder is for studying the AM115/AM215 course material with the course textbook. When the
student wants to study, review, or check their understanding, use the `study` skill in
`.agents/skills/study/SKILL.md`. Keep the student's notes in `my/`. Use only the public textbook,
downloaded into `textbook/` by `scripts/get_textbook.py`; do not ask for or use files from Canvas.
